# Проект по бинпоиску по файлу 150к строк с ютуб видосами

Датасет: https://www.kaggle.com/datasets/xtitanixx/youtube-videos 


## Про датасет
Датасет состоит из ютуб видосов. На кагле написано:  
> This dataset contains information about the last 10 videos uploaded by each YouTube channel, captured in early October 2025.

Так вот, это вранье! Там есть видосы и 19-летней давности (можно самому проверить запустив прогу)
Странный датасет. Имеет в себе:
- id, название видео
- id, название канала
- кол-во лайков, просмотров, комментариев
- дату публикации
- обложку

Из интересного в датасете можно вбить `100` коэффициент вовлеченности `(лайки + комментарии) / просмотры`.
По сути ничего быть не должно, но там что то есть!!

## Про сам проект
К сожалению датасет скудный по данным и мало что можно придумать прям *уникального*.
Есть вывод в веб по FastAPI. 
**Везде направление монотонности FFFF | TTTT, так как мы ищем чтоб что либо было больше чем заданное значение!**
**x - это проверяемый атрибут (лайки, комментарии, просмотры, вовлеченности)**
**check(x) - это соответствующая ей функция, проверяющая больше ли x, чем заданное значение**

### Реализовано
- Бинпоиск по просмотрам
- Бинпоиск по комментариям
- Бинпоиск по лайкам
- Бинпоиск по вовлеченности
- Небольшой веб-интерфейс на FastAPI
